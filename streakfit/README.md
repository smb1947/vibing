# StreakFit

StreakFit is a responsive React/Vite prototype for helping students reduce pre-gym friction and follow through on their gym routine.

The app is in:

```bash
streakfit/visual-prototype
```

## Run Locally

```bash
cd streakfit/visual-prototype
npm ci
npm run dev
```

## Build

```bash
cd streakfit/visual-prototype
npm run build
```

## Deploy On Vercel

Set the Vercel root directory to:

```bash
streakfit/visual-prototype
```

Vercel settings:

- Framework preset: `Vite`
- Install command: `npm ci`
- Build command: `npm run build`
- Output directory: `dist`
